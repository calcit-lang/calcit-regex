# 使用共享 native FFI crate / Adopt the shared native FFI crate

## 中文

- 使用 calcit_native_ffi 0.1.0 统一 buffer v1 descriptor、ownership、Cirru EDN transport 和 adapter。
- 删除仓库内重复模板，保持公开 symbol 与业务行为不变。
- 将 Calcit 项目要求同步到 0.13.57，并补充双语维护说明。

## English

- Use calcit_native_ffi 0.1.0 for buffer-v1 descriptors, ownership, Cirru EDN transport, and adapters.
- Remove repository-local boilerplate while preserving public symbols and behavior.
- Align the Calcit project requirement to 0.13.57 and add bilingual maintenance guidance.
