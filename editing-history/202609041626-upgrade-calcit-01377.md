# Upgrade Calcit baseline to 0.13.77 / 升级 Calcit 基线到 0.13.77

Issue: calcit-lang/calcit#666, child of calcit-lang/calcit#657.

- Updated only the declared Calcit baseline from 0.13.76 to 0.13.77.
- Kept the calcit-regex module and Rust crate versions unchanged.
- No Snapshot, regex API, native ABI, or release/tag changes were required.
- Validation uses a Calcit 0.13.77 binary built from the published release
  commit `5915ccf38ef3b57ea26897599646eefdbc9e3ba6`.

## Validation

- `caps --calcit-version 0.13.77 --strict --ci`
- Calcit 0.13.77 `calcit calcit.cirru --check-only`
- `calcit calcit.cirru analyze check-types --summary-only --format json`,
  unresolved Dynamic inventory, and deprecated-call inventory
- `calcit calcit.cirru ffi export --json --ns regex.core`
- `cargo fmt --check`, `cargo test` (5/5), and
  `cargo clippy --all-targets -- -D warnings`
- `cargo build --release` and `nm -gU` export audit (15 expected C ABI symbols)
- Calcit 0.13.77 `--trace-ffi` runtime smoke, including resource generation,
  reuse, and release
- README and compiled-pattern Markdown snippet checks
