# Regex docs discovery and Calcit upgrade / Regex 文档发现与 Calcit 升级

## 中文

- 新增 compiled regex 文档，索引 Result、Option、trait method 与 native resource 生命周期。
- 升级到 Calcit 0.13.64，并迁移 canonical Snapshot 与 deprecated pattern matching。
- 将共享 native transport helper 升级到 `calcit_native_ffi` 0.1.3。

## English

- Add compiled-regex documentation covering Result, Option, trait methods, and native-resource lifetime.
- Upgrade to Calcit 0.13.64 and migrate the canonical Snapshot and deprecated pattern matching.
- Upgrade the shared native transport helper to `calcit_native_ffi` 0.1.3.
